# AgentGuard

A Java-based security gateway designed to control and authorise AI-agent tool execution.

## Overview

AI agents can interact with external tools, retrieve information and perform actions. Without appropriate access controls, these capabilities can introduce security risks.

AgentGuard explores how a dedicated authorisation layer can enforce permissions before allowing agents to execute tools.

The project focuses on secure backend architecture, clean Java design and automated testing.



## Tech Stack

**Language:** Java  
**Build:** Maven  
**Testing:** JUnit 5  
**Planned:** Spring Boot, Spring Security, PostgreSQL

## Getting Started

Clone the repository and run the tests using Maven:

`mvn clean test`
